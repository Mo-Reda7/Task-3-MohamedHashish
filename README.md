# Recommendation System

## Project Description

This project implements a simple recommendation system using Python. It takes user preferences as input and recommends relevant items based on similarity and matching logic.

## Features

* User preference input
* Data loading from CSV file
* Recommendation generation
* Similarity-based matching
* Simple and interactive interface

## Technologies Used

* Python
* Pandas
* Scikit-learn (TF-IDF)
* NumPy

## Dataset

The project uses a CSV dataset containing items and their descriptions/features.

## How to Run

1. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the project:

   ```bash
   python recommendation_system.py
   ```

## Project Workflow

1. Load dataset from CSV file
2. Process text data
3. Convert text into numerical features using TF-IDF
4. Calculate similarity scores
5. Recommend the most relevant items

## Output

The system displays personalized recommendations based on user preferences.
